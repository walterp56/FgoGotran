# Third-party components

FgoGotranLocal uses Python packages listed in `requirements.txt` and controls a separately downloaded llama.cpp runtime.

- llama.cpp: <https://github.com/ggml-org/llama.cpp>
- Gradio: <https://github.com/gradio-app/gradio>
- FastAPI: <https://github.com/fastapi/fastapi>

llama.cpp, CUDA runtime files and GGUF models are not redistributed in this folder. Users are responsible for reviewing and following their respective licenses.
